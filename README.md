**Optimization Methods using Julia**
 - hands-on workshop -


I. Introduction to Optimization and Julia (1 h)
- Objective functions, constraints; why Julia is becoming a major language for scientific computing.
  
II. Derivatives, Gradients and Local Search (1 h)
- From derivatives to gradients and bracketing methods: understanding local improvement strategies.

III. First- and Second-Order Methods (1 h)
- Gradient Descent, Momentum, Conjugate Gradient and Newton methods.

IV. Direct Optimization Methods (1 h) 
- Derivative-free methods: Powell and Hooke–Jeeves search.

V. Stochastic Optimization (1 h)
- Noisy Descent, Simulated Annealing and Cross-Entropy methods.

VI. Population-Based Optimization (2 h) 
- Genetic Algorithms, Differential Evolution and Particle Swarm Optimization.

VII. Expression Optimization with Genetic Programming (1 h)
- Symbolic regression and tree evolution using Julia.
